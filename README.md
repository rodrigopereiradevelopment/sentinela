# Sentinela

Sistema modular de monitoramento, auditoria e segurança de sistemas.

## Objetivo

Monitorar dispositivos autorizados, coletar métricas e eventos, registrar auditorias e oferecer visibilidade sobre o estado de segurança do ambiente.

## Status

**Em planejamento.** O código será adicionado conforme os blocos do cronograma de 24 meses forem iniciados. Este repositório permanece propositalmente enxuto até que cada componente tenha finalidade definida.

## Estrutura prevista

- Backend: C# / ASP.NET Core
- Banco: PostgreSQL
- Agente local: Rust
- Dashboard desktop: Tauri + TypeScript
- App mobile: Ionic
- Integrações de segurança: Python
